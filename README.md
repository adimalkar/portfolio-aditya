## 🌊 About This Portfolio

A modern, animated portfolio website showcasing my work as a **Data Scientist & ML Engineer**. Built with Next.js 16 and featuring a custom **Three.js ocean wave background** with interactive mouse/touch controls.

### ✨ Key Features

- 🌊 **Interactive 3D Wave Background** - Custom Three.js ocean waves that respond to mouse movement
- 🚢 **Animated Ship** - A sailing ship that bobs on the waves
- ⭐ **Starfield & Aurora Effects** - Ambient background animations
- 💻 **Code Terminal Animation** - Typing effect in the hero section
- 📱 **Fully Responsive** - Optimized for all devices
- ⚡ **Blazing Fast** - Built with Next.js 16 App Router

## 🏃 Running Locally

### Prerequisites
- Node.js 18.17+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/adimalkar/developer-portfolio.git
cd developer-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
